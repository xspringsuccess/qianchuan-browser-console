# 千川网页规则台（独立浏览器版）

这是与开放平台 API 版本完全隔离的“GitHub Pages 静态看板 + 本机网页执行器”。本机执行器只在电脑开机时运行，使用独立 Chrome 用户目录；千川 Cookie、密码、验证码、规则和执行记录均不上传云端。

当前版本 0.5.0：已实现本机一次性会话、专用浏览器启动、账户与计划只读同步、规则草稿与评估、具体预算操作预览和取消。真实预算与计划启停尚未开放。

同步会读取专用浏览器中已打开的千川账户。看板显示账户首页的整体消耗，以及乘方、标准、全域和品牌的分项消耗。乘方和全域计划按当前已验证的商品数据源采集，遇到分页最多读取 25 页。标准和品牌的计划入口仍待验证。计划可以按账户和板块筛选，历史快照单独标记。

首页消耗用于展示。账户预算规则需要经过验证的同口径整账户消耗和净 ROI。当前网页采集尚未核实整账户净 ROI 来源，相关规则会等待口径验证。

在规则卡片点击“重新同步并生成操作预览”，程序会重新读取账户页面，仅在进度达到阈值且净 ROI 严格大于阈值时生成预览，展示账户/计划 ID、原生日预算、追加金额、新预算和触发原因。缺失预算、不限预算、缺失指标、不可编辑计划均不能生成预算操作。预览 5 分钟过期；更新数据或规则会使旧预览失效。重复读取同一快照不会重复建立预览。

预览只记录在本机，不会提交到千川；没有真实写入接口。规则表单保存时始终保持未启用。冷却时间已保存，真实执行适配阶段才会应用；目前不会自动周期读取页面。

## 隔离边界

- 独立目录：`E:\codex\千川网页执行器`
- 独立公开 GitHub Pages 仓库：`qianchuan-browser-console`
- 不使用 Cloudflare Worker、D1 或 GitHub OAuth App
- 独立本机数据库：`.local/`
- 独立浏览器用户目录：`%LOCALAPPDATA%\QianchuanBrowserConsole\`
- 不读取或修改 `E:\codex\千川`，不复用其数据库、授权或真实写入开关

## 本地验证

```powershell
node scripts/check.mjs
node --test tests/*.test.mjs
node scripts/static-dev.mjs
```

开发预览地址为 `http://127.0.0.1:8797`。日常使用双击根目录的 `启动千川网页执行器.cmd`；启动器会打开 GitHub Pages 看板和千川专用页面。不要直接从收藏夹打开看板：直接打开的页面没有本机会话令牌，无法连接执行器。

启动器使用软件渲染模式，以兼容 GPU 子进程受限的 Windows 环境。首次启动后，请只在启动器打开的专用浏览器窗口中登录千川。
